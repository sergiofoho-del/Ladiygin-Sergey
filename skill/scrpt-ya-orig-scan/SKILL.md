# Сохранить Скан (Scrpt_YA_Orig_Scan)

Навык повторяет логику userscript [Scrpt_YA_Orig_Scan 1.3.0](https://github.com/MasterGoodwin2/Scrpt_YA_Orig_Scan)
(MIT, MasterGoodwin2; тот основан на Archive Original Downloader) и расширяет её: диапазон страниц одним ZIP,
путь в архиве, подключение сканов к Excel. Распознавания нет — сохраняются только изображения.

Тот же механизм встроен в расширение «Яндекс Архив — сбор людей округи» (2.0.0+): отметка
«Сохранить Графические сканы?» кладёт сканы в папку `Archive_Scans` (с 2.1.0 — по кнопке «Выбрать куда сохранять
Excel, и начать» папка создаётся в выбранной папке рядом с `result.xlsx`; существующие файлы сканов пропускаются) и даёт в Excel столбец
«Локальная Ссылка на страницу». Для массового сбора вместе с данными людей используйте расширение;
навык — для отдельных страниц, диапазонов и подключения уже скачанных сканов.

## Как устроено (проверено на ya.ru, октябрь 2026)

1. Страница скана: `https://ya.ru/archive/catalog/<id дела>/<номер>`. В теге `__NEXT_DATA__`:
   `props.pageProps.currentNode.id` — id узла скана; `props.pageProps.breadcrumbs` — путь
   `[{type:'Archive', name:'ЦГА Москвы'}, {type:'Fund', code:'203'}, {type:'Inventory', code:'747'}, {type:'File', code:'15'}]`;
   `docNumber` — номер страницы (на SPA-переходах тег может быть от другой страницы — тогда HTML запрашивается заново).
2. `POST /archive/api/image-grant` с телом `{"nodeId": "<id>", "type": "original"}` (cookies сессии) →
   `{url, token}`; файл — `GET url` с заголовком `X-Archive-Image-Token: <token>`. Без входа в Яндекс — 401/403.
3. Проверки: `content-type` image/*, не HTML, размер ≥ 20 000 байт (иначе превью).
4. Пересжатие в JPG (по умолчанию качества 0.4; уровни — раздел «Качество») через canvas (размер в пикселях не меняется); если результат не меньше
   оригинала или пересжать не удалось — сохраняется оригинал. Пример: 5172×4222, 2,58 МБ → 0,97 МБ, 3–8 с на страницу.
5. Имя: `<Архив>_[ЯА]_<фонд>-<опись>-<дело>-<лист 4 цифры>.jpg`, например `ЦГА_Москвы_[ЯА]_203-747-15-0865.jpg`;
   путь из шапки страницы (в Excel, столбец «Архив хранения документа», текстом): `ЦГА Москвы/Фонд 203/Опись 747/Дело 15/Скан 865`
   (`link_scans.py` понимает и прежний вид с «Главная/Каталог/» впереди).

## Качество скачиваемого файла

Три уровня (определены здесь, в `scripts/ya_orig_scan.js` — `YaOrigScan.QUALITY`; расширение «Яндекс Архив» берёт те же значения
для типа обработки «Скачать графические образы страниц из списка ссылок», три флажка):

| Флажок | Идентификатор | Качество | Что делается |
|---|---|---|---|
| «Оригинальное» | `original` | 100% | файл сохраняется как отдан Яндексом, без пересжатия |
| «Среднее» | `medium` | 50% | пересжатие в JPG качества 0.5 |
| «Низкое» | `low` | 20% | пересжатие в JPG качества 0.2 |

Размер в пикселях не меняется ни на одном уровне; если пересжатый файл не меньше оригинала, сохраняется оригинал.
Имя файла от уровня не зависит, поэтому уже скачанный скан при другом уровне пропускается (удалите файл, чтобы скачать заново).
Вызов: `YaOrigScan.save({ from: 865, to: 880, quality: 'medium' })`; число (0.4, 1) тоже принимается.

## Сохранить сканы (Claude in Chrome)

Нужна вкладка ya.ru (или yandex.ru), где пользователь вошёл в Яндекс. Код `scripts/ya_orig_scan.js` выполняется
в этой вкладке (инструмент выполнения JavaScript), объявляет `YaOrigScan`:

```js
YaOrigScan.save();                         // текущая страница -> один JPG
YaOrigScan.save({ from: 865, to: 880 });   // диапазон того же дела -> один ZIP (JPG + info.txt, errors.txt)
YaOrigScan.save({ fileId: '<id дела>', pages: [12, 15], quality: 'original' });  // без пересжатия (100%)
```

Вызов возвращает Promise; итог также пишется в `window.__yaOrigScan` (`{ok, file, pages:[{page, name, w, h, origSize,
size, err}], cga}`) — его читают отдельным вызовом через несколько секунд (≈3–8 с на страницу, пауза между
страницами 1,2 с, `delay`). Перед большими диапазонами предупредите пользователя о времени и объёме (~1 МБ на скан).

Файл сохраняется обычной загрузкой браузера в папку «Загрузки». **Важно:** Chrome разрешает сайту одну
автоматическую загрузку; следующие он блокирует, пока пользователь не нажмёт «Разрешить» в запросе
«скачать несколько файлов» (или не разрешит ya.ru в `chrome://settings/content/automaticDownloads`).
Поэтому диапазон сохраняется одним ZIP. Если загрузка не появилась в «Загрузках», а `__yaOrigScan.ok === true`,
дело в этом разрешении — попросите пользователя разрешить автоматические загрузки для ya.ru сам; настройки
браузера не меняйте за него.

## Подключить сканы к Excel результата

Если сканы скачаны отдельно (userscript, этот навык, ZIP распакован в `Archive_Scans`), ссылки в result.xlsx
проставляются по столбцу «Архив хранения документа» — имя файла скана выводится из пути:

```bash
python scripts/link_scans.py "<папка результата>/result.xlsx" --scans /Volumes/DATA/Archive_Scans
```

В ячейке «Локальная Ссылка на страницу» — локальный путь папки сканов + имя файла
(`/Volumes/DATA/Archive_Scans/<файл>.jpg`), ссылка — `file://…`. Параметр `--scans` по умолчанию
`/Volumes/DATA/Archive_Scans`. Объединённые ячейки учитываются (ссылка ставится в первую ячейку группы).

## Ограничения

- Скачивайте только материалы, к которым у пользователя есть доступ, соблюдайте правила Яндекс Архива;
  выдерживайте паузы между страницами.
- Код зависит от текущего устройства сайта (`/archive/api/image-grant`, `__NEXT_DATA__`); при изменении API
  нужна правка `scripts/ya_orig_scan.js` и `page-scripts.js` расширения (функция `scanFetcher`).

## Локальный путь к папке сканов

Папка «Archive_Scans» по умолчанию — `/Volumes/DATA/Archive_Scans/`. В столбце «Локальная Ссылка на страницу» указывается локальный путь + имя файла
(`/Volumes/DATA/Archive_Scans/ЦГА_Москвы_[ЯА]_203-747-15-0865.jpg`), ссылка — `file://…`. Столбец «Архив хранения документа» (ранее «Ссылка на ЦГА Москвы»)
содержит путь «ЦГА Москвы/Фонд…/Опись…/Дело…/Скан…» и по нему выводится имя файла.

## Встроено в расширение (с версии 3.0.0)

Этот навык входит в расширение Chrome «Яндекс Архив — сбор людей округи» и работает внутри него — запускать скрипты в Терминале не требуется. Скрипты в `scripts/` оставлены как справочная копия логики и для проверок.
