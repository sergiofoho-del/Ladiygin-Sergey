# База данных yaarchive для скиллов анализа и отчётов

Лучшие готовые результаты обработки Яндекс Архива (ЦГА Москвы), собранные в одну базу SQLite. Подготовлено 05.11.2026.

## Какие результаты выбраны и почему

### Исповедные ведомости 1739–1864 → итог yaarchive 3.2.0 от 29.10.2026
Файл: `Исповедные_ведомости_1739-1864_итог_yaarchive-3.2.0.xlsx` (+ `…ged.gz` — GEDCOM, `…Отчёт.txt`). Вход: отладочный пакет расширения 2.3.0, 992 страницы, 44 документа (ф. 203 оп. 747 и один документ ф. 51 оп. 8).

| Результат | Людей | Без номера | Без имени | Без возраста | НП «не определён» | Полных (имя+номер+возраст) |
|---|---|---|---|---|---|---|
| 1.9.0 (58 971 стр., PR #7) | 58 971 | 4 752 | 7 537 | 4 577 | 1 389 | — |
| расширение 2.4.0 (result_2.4.0) | 58 246 | 3 739 | 6 296 | 3 356 | 0 | 80,7 % |
| **yaarchive 3.2.0 (выбран)** | **62 840** | **3 694** | 6 666 | 3 738 | **1** | **81,0 %** |

Почему 3.2.0: больше всего людей (+4 594 к 2.4.0), самая полная структура (отдельные имя, отчество, фамилия, родство, ID, ID отца/мужа у 37 173 человек, листы «Семьи», «Проверка», «Исправления»), принятые исправления (1 215), GEDCOM. Недостаток: имя не выделено у части записей (6 666), на проверку помечено 21 755 строк.

Известные ограничения: не загрузились страницы 1753 стр. 914, 1825 стр. 870, 1826 стр. 169; 25 строк документа ф. 51 оп. 8 д. 34 (1811, ревизская сказка, запущенная как исповедная) разобраны плохо — для анализа их лучше исключить (`document = 'Ревизская сказка'`); в 1795 г. номера людей в ведомости не проставлены; по 1753 г. — 4 943 человека (пропущена одна страница).

### Ревизские сказки → «Ревизская сказка 1850, Бутурлин, сканы 130–225»
Файл: `Ревизская_сказка_1850_Бутурлин_сканы_130-225.xlsx`. ЦГА Москвы ф. 51 оп. 8 д. 588, 9-я ревизия, имение майора Н. А. Бутурлина; 2 398 человек, 7 селений (с. Троицкое 538, д. Екатериненская 64, д. Черепкова 288, д. Рублева 225, д. Луки 198, д. Мякинина 245, д. Строгина 840). Других полных результатов по ревизским сказкам нет — это единственный. Пустых: «Лет в 1850» 565, «Лет по 8-й рев.» 1 309 (часть — родившиеся после 1834), «Семья №» 15. Возраст сверять со сканом (пропуск цифры сдвигает возрасты ниже по семье).

## Файлы
| Файл | Назначение |
|---|---|
| `yaarchive_db.sqlite.gz` | **база данных для скилла** (распаковать: `gunzip -k yaarchive_db.sqlite.gz`, 43,6 МБ) |
| `build_db.py` | пересборка базы из двух xlsx (слитые ячейки разворачиваются) |
| `Исповедные_…xlsx`, `…ged.gz`, `…Отчёт.txt`, `Ревизская_…xlsx` | исходные результаты |
| `SHA256SUMS.txt` | контрольные суммы |

## Схема базы (SQLite, только чтение)
- `confession_people` (62 840): `year, document, settlement, household_no, person_no, person_text, given_name, patronymic, surname, sex, age, age_prev_revision, birth_year, relation, status, note, to_check, corrected, id, father_or_husband_id, page_url, archive_path`
- `confession_families` (7 127): `year, document, settlement, household_no, people, males, females, head, members`
- `confession_pages` (992): `year, document, doc_type_by, page, people, remarks, page_url`
- `confession_checks` (21 755): `year, page, person, id, what, page_url`
- `revision_people` (2 398): `scan, village, family_no, sex, person_text, relation_to_head, age_1834, age_1850, note, estate`
- `meta`: источники, дата сборки, число строк.
Пол: `м` / `ж`. Годы 1739–1864 (45 лет, 44 документа). `birth_year` ≈ год документа − возраст. Индексы: year, settlement, surname, id, village.

## УКАЗАНИЕ ДЛЯ СКИЛЛА (вставить в SKILL.md)
```
## База данных (читать напрямую, только чтение)
Данные — SQLite-файл yaarchive_db.sqlite. Не пересобирай и не меняй его; результаты анализа сохраняй отдельно.
Где искать файл (по порядку):
1. {папка скилла}/data/yaarchive_db.sqlite
2. файл проекта «ладыгин сергей»: yaarchive_db.sqlite.gz → gunzip -k
3. GitHub (репозиторий публичный): git clone --depth 1 https://github.com/sergiofoho-del/Ladiygin-Sergey, файл data/db/yaarchive_db.sqlite.gz → gunzip -k
4. нет базы — собрать: python3 data/db/build_db.py <Исповедные…xlsx> <Ревизская…xlsx> yaarchive_db.sqlite
Открывать так: sqlite3.connect("file:yaarchive_db.sqlite?mode=ro", uri=True).
Таблицы и поля — см. раздел «Схема» в data/db/README_БД.md. Исповедные: confession_people (+families, pages, checks); ревизские: revision_people.
Правила: (1) все выводы — запросами SQL, не по памяти; (2) исключай document='Ревизская сказка' из статистики исповедных; (3) строки с непустым to_check — предположительные, указывай их долю; (4) год рождения ≈ приблизительный; (5) в отчёте всегда давай ссылки page_url / archive_path для проверки по скану; (6) называй источник из таблицы meta.
```
Примеры: `select settlement, count(*) from confession_people where year=1850 group by 1;` · `select village, count(*), sum(sex='м') from revision_people group by 1;` · `select year, count(*) from confession_people group by 1 order by 1;`
