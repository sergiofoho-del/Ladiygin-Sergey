# Ladiygin-Sergey

Инструменты для сбора сведений о родственниках по документам Яндекс Архива.

- `yaarchive/` — общий скрипт обработки (все навыки и справочники в одном файле, Excel + GEDCOM, «Исправление ошибок»).
- `yandex-archive-extension/` — расширение Chrome: собирает расшифровки страниц Яндекс Архива
  (ревизские сказки, исповедные ведомости) в Excel, по одной строке на человека.
- `skill/yaarchive-revision-rows/` — скилл Claude с тем же алгоритмом на Python, тестами и описанием.
- `skill/scrpt-ya-orig-scan/` — скилл «Сохранить Скан»: оригиналы сканов Яндекс Архива (JPG 40%, диапазон — ZIP)
  по логике [Scrpt_YA_Orig_Scan](https://github.com/MasterGoodwin2/Scrpt_YA_Orig_Scan) (MIT) и подключение сканов к Excel.
  С версии 1.8.0 — `scripts/revision_people.py`: ревизские сказки по людям (родство, ID отца/мужа для древа,
  отчество, два возраста, год рождения, выбытие, селение и сословие) с выгрузкой в Excel.

## Установка расширения

1. Скачайте репозиторий: зелёная кнопка «Code» → «Download ZIP», распакуйте.
2. В Chrome откройте `chrome://extensions`, включите «Режим разработчика».
3. «Загрузить распакованное расширение» → выберите папку `yandex-archive-extension`.

## Версия 3.1.0: общий скрипт yaarchive и расширение 2.3.0

**Установка на macOS 12+:** скачайте `releases/3.1.0/yaarchive-3.1.0-macOS.zip`, распакуйте, правый щелчок по
`Установить.command` → «Открыть». Установщик сам найдёт или поможет поставить Python, поставит openpyxl, положит
скрипт в папку со ссылками, скопирует расширение в «Документы» и откроет страницу расширений Chrome.

- `yaarchive/` — **общий скрипт**: все навыки, скрипты и справочники в одном файле `yaarchive.pyz`. Следит за папкой
  со ссылками и сам обрабатывает пакеты расширения: исповедные ведомости и ревизские сказки → Excel + GEDCOM (MyHeritage).
  Навык **«Исправление ошибок»** предлагает исправления (номера, дворы, имена, возрасты, родство, дозагрузка страниц)
  и применяет их только после подтверждения — в окне скрипта или в листе «Исправления» Excel. Подробно: `yaarchive/README.md`.
- **Расширение 2.3.0**: данные страниц и `run_summary.json` сохраняются всегда (вход общего скрипта); Excel постранично —
  «Год» и три столбца ссылок слиты по странице, «Ссылка на ЦГА Москвы» — текст; «Номер» перед «Человек»;
  НП «не определён» → следующий определённый, повторный НП — к первичному; цвета НП закреплены за названием, мужчины —
  голубые, женщины — розовые, ошибки — светло-красные; флажки «Выбрать куда сохранить» для сканов и result.xlsx,
  одна кнопка «Начать»; папка запуска с версией.

Архивы: `releases/3.1.0/` — комплект для macOS, `yaarchive.pyz`, расширение 2.3.0, навыки.

## Версия 2.1.0: папка результатов и Archive_Scans

- Кнопка «Выбрать куда сохранять Excel, и начать»: в выбранной папке сохраняется `result.xlsx` и создаётся папка
  `Archive_Scans` для графических сканов (навык «Сохранить Скан», логика Scrpt_YA_Orig_Scan).
- Если файл скана уже существует, он пропускается — обработка переходит к следующему.
- Ссылки в Excel на сканы в этом режиме — `Archive_Scans/<файл>.jpg` (рядом с result.xlsx).

Архивы: `releases/2.1.0/`.

## Ревизские сказки → Excel (скилл 1.8.0)

```bash
cd skill/yaarchive-revision-rows
python scripts/revision_people.py папка_страниц/ --out-xlsx Сказка_1850.xlsx \
    --source "ЦГА Москвы, ф. 51, оп. 8, д. 588" \
    --url "https://ya.ru/archive/catalog/bfed2966-e671-4c18-bbb0-a9551ad28f8e/{page}"
python tests/test_revision_people.py
```

На входе — данные страниц Яндекс Архива (`__NEXT_DATA__`, .json/.html) или `pages.json` от `extract_rows.py`;
сканы не распознаются заново. Особенности формы собраны по сказке 1850 г. по имению Н. А. Бутурлина
(ф. 51, оп. 8, д. 588, сканы 130–225). Пример: `examples/Пример_ревизская_сказка_1850_стр165.xlsx`
(д. Черепкова, семьи 23–24, 28 человек; итоги налицо 14 м / 11 ж совпали со сканом).

## Данные

`data/Ревизская_сказка_1850_Бутурлин_сканы_130-225.xlsx` — ревизская сказка 1850 г. (9-я ревизия) по имению
майора Н. А. Бутурлина, ЦГА Москвы, ф. 51, оп. 8, д. 588, сканы 130–225
([Яндекс Архив](https://ya.ru/archive/catalog/bfed2966-e671-4c18-bbb0-a9551ad28f8e/130)): 2398 человек —
с. Троицкое (с дворовыми), д. Екатериненская, Черепкова, Рублева, Луки, Мякинина, Строгина.
Собрано из машинного распознавания Яндекса; возраст для родословной сверяйте по скану (см. лист «Об источнике»).
